# Django Templates Editor

​	org.kacprzak.eclipse.django.editor.plugin_1.4.2.202405312204.jar

and it is simple as dropping this into the `plugins` folder in your Eclipse install and restarting Eclipse and on an HTML file in your project you should hen see on a right-click Open With > Django Editor.
